# private/

Dossier de travail pour les **donnees sources reelles**. Son contenu n'est jamais
versionne (voir `.gitignore` local) : ce sont des donnees personnelles de temps de
travail, et le depot a vocation a etre public (portfolio).

Ce qu'on y depose :

- le proto Excel historique (`Calendrier Pointage *.xlsx`)
- les exports CSV bruts de la pointeuse
- les dumps de base contenant de vraies donnees

Ce qu'on n'y depose pas :

- la specification tiree de ces fichiers, qui va dans `docs/` et qui, elle, est versionnee
- les jeux de donnees de demonstration, qui sont fictifs et vivent dans les fixtures
